GUARDIAN CONSTRUCTION — EmailJS Setup Guide
===========================================

STEP 1 — Create your EmailJS account
--------------------------------------
1. Go to https://www.emailjs.com and sign up (free)
2. Free plan = 200 emails/month. Paid = $15/mo for unlimited.


STEP 2 — Connect your email (Email Service)
--------------------------------------------
1. In EmailJS dashboard → "Email Services" → "Add New Service"
2. Choose Gmail, Outlook, or any SMTP email
3. Connect your Guardian Construction email (info@guardianconstructionmi.com)
4. Click "Connect Account" and authorize
5. Copy the SERVICE ID that appears (looks like: service_abc1234)


STEP 3 — Create your Email Template
-------------------------------------
1. In EmailJS dashboard → "Email Templates" → "Create New Template"
2. Set the template up like this:

   Subject:
   ──────────────────────────────────────────────────────────
   New Lead: {{service}} Request from {{from_name}} in {{city}}
   ──────────────────────────────────────────────────────────

   Body (HTML or Text):
   ──────────────────────────────────────────────────────────
   New estimate request from your website.

   Name:     {{from_name}}
   Phone:    {{phone}}
   Email:    {{reply_to}}
   City:     {{city}}
   Service:  {{service}}
   Message:  {{message}}
   Page:     {{page_source}}

   ──────────────────────────────────────────────────────────
   Reply directly to this email to respond to the lead.
   ──────────────────────────────────────────────────────────

3. Under "To Email" set it to: info@guardianconstructionmi.com
4. Set "Reply To": {{reply_to}}  ← this lets you reply directly to the customer
5. Save the template
6. Copy the TEMPLATE ID (looks like: template_xyz9876)


STEP 4 — Get your Public Key
------------------------------
1. In EmailJS dashboard → top right → "Account"
2. Under "API Keys" → copy your PUBLIC KEY (looks like: abc123XYZdef456)


STEP 5 — Add your credentials to the website
---------------------------------------------
In EVERY HTML file (index.html + all 59 city pages), find this block:

    var PUBLIC_KEY   = "YOUR_PUBLIC_KEY";
    var SERVICE_ID   = "YOUR_SERVICE_ID";
    var TEMPLATE_ID  = "YOUR_TEMPLATE_ID";

Replace with your actual values, for example:

    var PUBLIC_KEY   = "abc123XYZdef456";
    var SERVICE_ID   = "service_abc1234";
    var TEMPLATE_ID  = "template_xyz9876";

TO DO THIS EFFICIENTLY IN GITHUB:
  - In your GitHub repo, use the search bar to find "YOUR_PUBLIC_KEY"
  - Edit one file, then repeat for each file
  - OR use a find-and-replace tool on your computer before uploading

SHORTCUT: Since all 60 files have the same placeholder text, you can
run a global find-and-replace in VS Code or any text editor before
uploading to GitHub. Replace all three placeholders at once.


STEP 6 — Test it
-----------------
1. Deploy to Vercel
2. Fill out the form on your live site
3. You should receive an email within seconds
4. Check your EmailJS dashboard under "Activity" to see submission logs


WHAT EACH FORM FIELD SENDS TO YOU
------------------------------------
from_name    → Customer's full name
phone        → Their phone number  ← most important for follow-up
reply_to     → Their email (you can reply directly from your inbox)
city         → City they're in (pre-filled on city pages)
service      → Which service they selected
message      → Any extra details they typed
page_source  → URL of the page they submitted from (so you know which city)


TROUBLESHOOTING
----------------
- Form says "Something went wrong" → Check browser console for EmailJS error
- Not receiving emails → Check EmailJS Activity log for delivery status
- Emails in spam → Add EmailJS to your Gmail/Outlook safe senders list
- Over 200/month limit → Upgrade EmailJS plan ($15/mo) or switch to Formspree
