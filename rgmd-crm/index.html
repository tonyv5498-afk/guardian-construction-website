Firebase Setup Required

To use this CRM, you need a free Firebase project. Follow these steps:

  1. 1 Go to console.firebase.google.com → Create a project
  2. 2 Enable Authentication → Sign-in method → Google
  3. 3 Create a Firestore Database (start in production mode)
  4. 4 In Firestore Rules, paste: allow read, write: if request.auth != null;
  5. 5 Copy the Firebase config into index.html

Firebase free tier (Spark plan) is more than enough for a small CRM.
